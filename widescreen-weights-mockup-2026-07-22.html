Ant Hill · Widescreen Layout Review · 2026-07-22

The weights are backwards

On widescreen, the roster owns the widest column but only ever holds a handful of rows — the rest is dead whitespace. The inspector, the dossier you're actually reading, is pinned to a fixed 480–520 px rail where long values wrap two and three lines. Heavy content in the small box; light content in the big box. This plan flips the split to follow where your attention actually goes.

01

Today the split is pane-list: flex 1 (grows unbounded) next to pane-inspector: clamp(480px, 32vw, 520px) (fixed). At the 1680 px frame the table gets ~1160 px, the inspector ~520 px.

Backwards

The empty column is the wide one. The roster caps out at a few rows, so the widest surface on screen is mostly blank — while the reading surface is the pinched one.

Wrapping

Dense dossier in a 520px rail. Key/values like "in 142k · out 284 · cached 140k · total 142k" wrap to 2–3 lines; the "Available controls" prose stacks into a tall ribbon. The content you're reading fights for room the empty table isn't using.

02

Three ways to fix it

ApproachWhat changesTrade-off
A · Flip the ratio Roster shrinks to a scannable rail; inspector becomes the dominant reading panel.

Master–detail convention: the detail dominates.

 Full 5-column table only shows when nothing is selected.
B · Densify in place Keep the wide table; give the inspector a 2-column spec grid so values stop wrapping.

Smallest change.

 Doesn't fix the core feel — the thing you're reading is still the small box next to a blank one.
C · Hybrid ◆ RECOMMENDED Do both: roster → rail (~40%), inspector → reading panel (~60%) with the 2-column spec grid.

Flips the weight and kills the wrapping.

 Two CSS surfaces to touch instead of one. Roster loses its extra columns while an agent is open — but those live in full in the inspector anyway.
03

Proposed — reading-focused split

When an agent is selected: roster collapses to a rail (dot · message · one metric, with model/context/access folded into a compact meta line), and the inspector expands into the reading surface with a spec-sheet grid. Deselect and the roster springs back to the full-width 5-column table (unchanged).

Balanced

Space follows attention. The panel you read holds the majority of the width; the index you scan is a tight rail. No blank megacolumn.

Legible

Values stop wrapping. A 2-column spec grid turns the technical dump into a scannable sheet; long fields (Latest call, Directory) span both columns instead of stacking to three lines.

Preserved

Nothing lost. Model / context / access move to the rail's meta line and the full dossier — the columns aren't deleted, they're where you were already looking.

04

Implementation

Four surgical edits in src/web/styles.css, plus one class toggle in app.js so the split only flips when an agent is selected.

1 · The split — pane widths react to a selection
/* .app-body gets a state hook when an agent is open */
- .pane-list      { flex: 1; }
- .pane-inspector { width: clamp(480px, 32vw, 520px); }
+ /* default (nothing selected): full-width table, no drawer */
+ .pane-list      { flex: 1; }
+ /* agent selected: rail + reading panel */
+ .app-body[data-inspecting] .pane-list      { flex: 0 0 clamp(360px, 38%, 460px); }
+ .app-body[data-inspecting] .pane-inspector { flex: 1; width: auto; }
2 · Rail rows — collapse 5 columns to dot · message · metric
/* when inspecting, the roster row drops to a 3-track grid; */
/* model / context / access fold into a .rail-meta line     */
+ [data-inspecting] .work-row {
+   grid-template-columns: 1.1rem minmax(0,1fr) auto;
+ }
+ [data-inspecting] .work-row .col-model,
+ [data-inspecting] .work-row .col-access { /* → .rail-meta */ }
3 · Spec grid — technical readout stops wrapping
- .signal-tech dl { display: block; }  /* single column, wraps */
+ .signal-tech dl {
+   display: grid;
+   grid-template-columns: repeat(2, minmax(0, 1fr));
+   gap: 0.15rem 1.4rem;
+ }
+ .signal-tech dl > .kv-span { grid-column: 1 / -1; }  /* long fields */
4 · The toggle — one line where selection is set/cleared
// app.js — wherever the inspector opens/closes
+ appBody.toggleAttribute('data-inspecting', Boolean(selectedId));
