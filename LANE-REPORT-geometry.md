# Geometry Lane Report

## What the lane was

Add a local-only real-Chromium gate for the integrated agent RHSP. The gate
starts this checkout on an ephemeral loopback port, stops the page's live boot
loop, injects one deterministic shared-cwd/quarantined Cursor fixture through
`globalThis.TheAntHill`, and measures the settled drawer at 1357x738,
1530x862, and 390x844. Port 4701 was never opened, stopped, or restarted.

  y=811.375, proving the transcript overflowed its collapsed wrapper.
- The same two claims remained red on follow-up head `07a0c93`, so the gate was
  not weakened. CSS follow-up `20e8ba9` made both claims green.

## What shipped, file and fence

Only `docs/rhsp-geometry-gate/drawer-geometry.test.ts` plus this report. The test:

- resolves the existing project/machine gstack browser without a new dependency;
- uses a deterministic unavailable agent with native-disabled input, Send,
  Focus, and Interrupt;
- records all required rectangles, ordering, containment, minimum feed height,
  horizontal overflow, and declared vertical scroll owners;
- proves desktop owners are exactly transcript feed + evidence desk and mobile's
  sole drawer-body owner is `.drawer-grid`;
- proves the mobile document is locked only while the fixed sheet is open;
- fails loudly on a missing browser, hidden pane, missing selector, or any 0x0

- writes screenshots only to `/tmp`.
